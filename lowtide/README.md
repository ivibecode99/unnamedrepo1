# LOWTIDE

*A story RPG about listening.* The sea of an old world drained overnight and nobody remembers why. You follow a stray light
down the dry seabed into LOWTIDE, a hidden country of lantern-lit reef towns, ship-cities and salt ruins, where every
person carries a small lantern that holds their memories. Light them together — by listening, by force, or somewhere in
between — and find out where the sea went.

One portable C99 core, one data pipeline, one game on every platform. Everything — art, music, story, font — is original and
generated by the scripts in `tools/` and `content/`.

## Controls
| Action | Keyboard (default) | Gamepad | Game Boy / GBA / R36S |
|---|---|---|---|
| Move | Arrows / WASD | D-pad / left stick | D-pad |
| Confirm / interact | Z, Space | A | A |
| Cancel / run / shield (in battle) | X, Backspace | B | B |
| Menu | Enter, C | Start | START |
| Item shortcut / flee | Right Shift, V | Back | SELECT |
| Quit | close window | — | hold START+SELECT 1.5 s (desktop/R36S) |

Touch (web/mobile): on-screen D-pad, A, B, START, SELECT appear on first touch. Keys are remappable in OPTIONS (desktop, web).

**Battle:** ATTACK (time the bar), **LISTEN** (CHECK and context-sensitive options; enemies have clever, non-violent routes),
ITEM, **RELEASE** (let them go, once they are ready). On the enemy turn your lantern flame moves in the box; **B** raises a short shield.
Accessibility (OPTIONS): text speed, reduce flashing, slow-dodge assist, volume, remappable keys.

Saving: stand at a lantern post (one per zone) — 3 slots. Battery SRAM on Game Boy/GBA, a `lowtide.sav` file on desktop/R36S, `localStorage` in the browser.
Endings: Peace, Neutral, Fight and a hidden True ending (needs actions across all five zones). New Game+ remembers your last ending.

## Building
Requirements: Python 3 (+ numpy for music previews), a C compiler, SDL2 dev files for desktop targets.
```
make native            # Linux desktop build -> build/linux-x64/lowtide     (or: cmake -S . -B build/cmake && cmake --build build/cmake)
make test              # unit tests: script VM, save/load, battle emitters
tests/run_bots.sh      # playthrough bots for all four endings (runs the real game, title screen to credits)
tools/build_gb.sh      # GBDK-2020 -> build/gb/lowtide.gbc        (GBDK at /opt/gbdk or $GBDK)
tools/build_gba.sh     # arm-none-eabi-gcc -> build/gba/lowtide.gba (no libtonc/devkitARM needed)
tools/build_web.sh     # Emscripten -> build/web/index.html
tools/package.sh       # everything the host can build -> dist/
```
Cross builds with CMake: `-DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake` (Windows), `cmake/aarch64-linux.cmake` (+`-DLT_R36S=ON` for the R36S, 3x scale
at 640x480), set `SDL2_MINGW` / `SDL2_AARCH64` to SDL2 dev trees. macOS universal: see `.github/workflows/release.yml`.

Debug/test hooks (SDL build): `--headless --frames N --keys file --shot FRAME:out.png --warp MAP X Y DIR --var IDX=VAL --seed N --sav FILE --dmg --bridge`.
