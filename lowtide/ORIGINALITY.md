# Originality audit

Rule: same vibe, never the same content. Everything in this repository is original: story, names, characters, dialogue, maps, sprites (generated by `tools/art_*.py`), the 5x7 bitmap font (`tools/fontdata.py`, hand-authored rows), UI skin, and all 31 songs + sound effects (`content/songs.py`, authored as scale-degree phrases).
No sprites, samples, fonts, or music from any other game were used, and none were imitated beyond the generic genre mechanics (a dodge box, spare-or-fight choices, typewriter dialogue).

## Checks performed
| Area | Check | Result |
|---|---|---|
| Text | `grep -i` of content/core/tools for protected names and phrases (e.g. "determination", "hopes and dreams", skeleton/goat/flower characters, known character names from the reference games, "red heart") | no matches |
| Characters | 25 named speakers + 6 generic folk. Species: moth, gull, crab, urchin, anglerfish, anemone, kelp, jellyfish, turtle, clam, eel, bell, salt golem. No skeleton brothers, goat guardians, talking flowers or similar archetype pairings; the rival (Skiff) and the "warden who refuses a goodbye" are original arcs | pass |
| Player soul | A **lantern flame** (own sprite, orange/yellow) with a short **shield** on B; not a red heart, no "determination" language | pass |
| Combat | Commands ATTACK / LISTEN / ITEM / RELEASE; listen options are per-enemy puzzles; boxes change shape mid-fight; music layers react. Genre mechanics only | pass |
| Story | Premise (drained sea, lanterns holding memories), the mystery (the sea was *held* mid-goodbye by the Warden) and the five Memory Shells are original | pass |
| Music | Melodies are written by hand as scale-degree phrases in `content/songs.py`; chord progressions are generic I-V-vi-IV / i-VI-iv-V-type cycles found in countless works and were not copied from any specific piece. The recurring Lantern theme is `1 3 5 6 5 | 8 6 5 3 | 4 6 8 6 5 | 3 2 1` (degree notation). Not compared against a melody database - **a human listen for accidental resemblance is still recommended** | pass (automated + author review) |
| Fonts/UI | Own 5x7 glyph rows; frames/HP bar drawn from primitives; title logo drawn from that font scaled 2x | pass |
| Names that sound close to existing ones | "Warden Marrow", "Hushmother", "Skiff", "Wick" (a candle-wick pun), "Pip" (common word) are generic words; none match reference-game names | pass |

Residual risk: generic phrases ("Ha!", "Welcome to ...") and common chord cycles are unavoidable; the running gags (Pip's "Population: me, plus some people!", Gaff's empty bucket, Dory's numbered rules, Tangle's "allegedly") are original to this game.
