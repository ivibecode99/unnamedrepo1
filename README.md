# Capt & Co.

A complete, original **3D collect-a-thon platformer** (Godot 4) plus a **Pocket Edition** 2D demake for **Game Boy / Game Boy Color / Game Boy Advance**.
You are **Pip**, a sleepy hero with **Capt**, a living, sassy, flying hat. Throw Capt to hit enemies, bounce off him and **capture** creatures and objects to use their abilities. Collect **66 Stars** across six kingdoms to power the Airship Hiccup and chase Baron Von Grumblebelt to his giant Music Box.

> Every character, name, model, tune and sound effect is original and generated in code (procedural meshes, a software synthesizer, procedural pixel art). No third-party art or audio is used – see [CREDITS.md](CREDITS.md).

* **Play in the browser:** `web/` landing page + `play/` (deployed by the *Build Web* workflow; see below) – or `tools/build.sh web && python3 -m http.server -d build/site 8080`.
* **Play guide / controls:** [docs/PLAY_GUIDE.md](docs/PLAY_GUIDE.md)
* **R36S / R36H handheld:** [docs/R36S.md](docs/R36S.md)
* **Flash the Pocket Edition to a cartridge:** [docs/FLASHING.md](docs/FLASHING.md)
* **Plan / status / known gaps:** [docs/PLAN.md](docs/PLAN.md) · [TODO.md](TODO.md)

## What is in the game
| | |
|---|---|
| Kingdoms | Fernwhistle Forest, Sizzle Sands, Tinkertown, Splashbottom Bay, Frostnip Peaks, Cinder Skies (sky/volcano), Airship Hiccup hub, Grumblebelt's Music Box (final) |
| Collectibles | **66 Stars** (10 per kingdom: boss/summit, 2 platforming, 2 hidden, 2 NPC quests, coin goal, shop, capture challenge + 3 in the hub + 2 in the final level), a **kingdom-specific coin** per kingdom and a **shop** in each |
| Bosses | 5 kingdom bosses (Mossback Mogul, Madame Scarabella, Gearhead Gus, Captain Brinebeard, Frostbite Frank) with 3 phases each + the final boss **Baron Von Grumblebelt** (4 phases) |
| Capture | **18** capturable creatures/objects with unique movement or abilities |
| Story | animated intro, arrival and boss cutscenes, ending, **44 NPCs** with funny dialogue, skippable text |
| Moves | run, jump, triple jump, long jump, backflip, ground pound, wall jump, swim, hat throw, hat spin, roll, dive |
| Systems | 3 save slots (checksummed, atomic writes, versioned), pause menu, settings (volume, key rebinding, camera invert/sensitivity, quality preset, text speed, fullscreen), keyboard/mouse + gamepad |
| Music & SFX | 12 original synthesized tracks (title, hub, one per kingdom, castle, boss, final boss, victory) and 40 sound effects, all generated by `game/audio/*.gd` |

## Run it from source (any desktop)
1. Install **Godot 4.4.1** (standard build) from https://godotengine.org/download/archive/4.4.1-stable/
2. Import once (creates the script-class cache): `godot --headless --path game --import`
3. Run: `godot --path game` (or open `game/project.godot` in the editor and press F5).
   Options: `-- --world=forest` jumps straight into a kingdom (uses save slot 1); `-- --handheld` forces the R36S preset.

## Build every target
`tools/build.sh <target...>` (set `GODOT=/path/to/godot`, templates must be installed: *Editor → Manage Export Templates*, or unzip `Godot_v4.4.1-stable_export_templates.tpz` into `~/.local/share/godot/export_templates/4.4.1.stable/`).

| Command | Output |
|---|---|
| `tools/build.sh test` | runs the headless test suites |
| `tools/build.sh linux` | `build/linux-x86_64/CaptCo.x86_64` |
| `tools/build.sh windows` | `build/windows/CaptCo.exe` |
| `tools/build.sh macos` | `build/macos/CaptCo.zip` (universal x86_64 + arm64 `.app`) |
| `tools/build.sh web` | `build/web/` + `build/site/` (landing page + `/play`) – single-threaded export, works on any static host |
| `tools/build.sh r36s` | `dist/CaptCo-r36s-arm64.zip` (Linux ARM64 + launcher + gamepad mapping) |
| `tools/build.sh pocket-gb` | `pocket/gb/build/captco.gb` and `captco.gbc` (needs GBDK-2020: `export GBDK_HOME=/opt/gbdk`) |
| `tools/build.sh pocket-gba` | `pocket/gba/captco_pocket.gba` (needs devkitARM + Butano: `export DEVKITARM=/opt/devkitpro/devkitARM BUTANO=/path/to/butano/butano`) |
| `tools/build.sh dist` | zips everything under `dist/` |

### macOS notes
The preset exports a universal `.app` zip, ad-hoc signed. To distribute outside your own machine you need an Apple Developer ID: set `codesign/*` and `notarization/*` in `game/export_presets.cfg` and run on macOS.

### Web hosting
Serve `build/site` from any static host (GitHub Pages works; the single-threaded export needs no special headers). The *Build Web* workflow deploys it to GitHub Pages: enable **Settings → Pages → Source: GitHub Actions**.

### R36S / R36H
See [docs/R36S.md](docs/R36S.md): unzip `CaptCo-r36s-arm64.zip` into the *ports* folder. Handheld mode is automatic on a Linux arm64 device with a screen ≤ 800×600, or force it with `--handheld` / `CAPT_HANDHELD=1`.

### Pocket Edition from source
```
python3 pocket/tools/export_gb.py && python3 pocket/tools/export_gba.py     # regenerate art, levels, music (needs Pillow)
# GB + GBC
export GBDK_HOME=/path/to/gbdk-2020 ; make -C pocket/gb all                  # -> pocket/gb/build/captco.gb, captco.gbc
# GBA (Butano C++)
git clone https://github.com/GValiente/butano ; export DEVKITARM=/opt/devkitpro/devkitARM DEVKITPRO=/opt/devkitpro
make -C pocket/gba LIBBUTANO=$PWD/butano/butano                              # -> pocket/gba/captco_pocket.gba
# emulator tests
pip install pyboy pillow && python3 pocket/tools/../tests/test_gb.py
xvfb-run -a python3 pocket/tests/test_gba.py                                 # needs mgba, xdotool, imagemagick, arm-none-eabi-nm
```
The CI workflow pins the Butano revision the GBA code was developed against (`67afc03`).

## Tests
`tools/build.sh test` runs `game/tests/*`: data validators (≥60 stars, ≥25 NPCs, ≥15 capturables, dialogue/quest consistency), input map, **save/load** (round trip, corruption, migration, slots), **movement & collision** (all jumps, wall jump, ground pound, swim, no tunnelling), **capture**, **boss** fights (every boss), each **kingdom** builds, UI/menus, scene flow, and the audio synth.

# Also in this repo: QOG


A single-user, **no-backend** web app for scanning, cataloguing, grading and "slabbing" trading & sports cards.
Static HTML/CSS/JS only – no server, no login. All data stays in your browser (localStorage + IndexedDB).

## Run it
Camera access needs `https://` or `localhost`:

```
python3 -m http.server 8000     # then open http://localhost:8000
```
or publish the folder on GitHub Pages / Netlify / any static host.

## Features
- **Scan**: pick any camera; **Fast slide** mode auto-captures each card as you slide it in; **Manual** mode with review/retake; **Upload** scans (bulk). Front only or front + back.
- **Auto-identify** (TCG): in-browser OCR (Tesseract.js) + free card databases – Pokémon (pokemontcg.io), Magic (Scryfall), Yu-Gi-Oh! (YGOPRODeck) – for full stats, prices and HQ art. Sports cards (baseball, basketball, football, hockey, soccer, golf, …) use manual fields.
- **Collection**: search/filter/sort, edit, export **CSV / Excel**, listing sheet, full JSON backup/restore.
- **Slab Studio**: choose a scan, an upload or a web HQ image → estimated grade (centering/corners/edges/surface, adjustable) → branded label (your logo, colours, font) at exact print size, transparent-background slab PNG/JPG, and slab + info sheet as PDF/PNG/JPG/WebP.
- **eBay / CollX**: those sites can't be posted to from a serverless page, so the app builds title/description/photos and opens their listing page.

Grades are automated estimates, not PSA/BGS/SGC grades.
